# Euro Quant & Markets Internship Tracker

Tracker européen des stages Front Office (Trading, Market Making, Structuration, Quant Research/Dev, Data Science Finance & Commodities) à Paris, Londres, Genève, Amsterdam, Francfort et Milan.

## Structure du projet
- `data/companies.json` : Catalogue de 45 acteurs majeurs (Banques FR/EU/US, Brokers comme Marex, Maisons de négoce Commodities, Market Makers et Hedge Funds Quant).
- `data/internships.json` : Base des offres actives (alimentée par le scraper et les ajouts manuels).
- `index.html`, `style.css`, `app.js` : Interface web statique (à venir à l'étape 2).
- `scraper/fetch_jobs.py` : Script Python de collecte automatisée via GitHub Actions (à venir à l'étape 3).
